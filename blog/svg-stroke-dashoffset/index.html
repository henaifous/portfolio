Draw a route with SVG stroke-dashoffset

A path that draws itself is one of the cheapest, cleanest animations on the web: no library, no canvas, a few lines of CSS. This guide builds one from the smallest version up to a colored route with a dot riding its head.

The trick

A stroke can be dashed. stroke-dasharray sets the length of each dash and gap, and stroke-dashoffset slides that pattern along the path. Make one dash as long as the whole path, push it out of view with the offset, then animate the offset back to zero. The line appears to draw itself.

The only awkward part is knowing the length of the path. SVG has a shortcut: set pathLength and the browser treats the path as if it had that length, so every dash value is relative to it. With pathLength="1", a dash of 1 is the whole path.

The smallest version

One path, a few declarations and a keyframe. No script.

The dasharray is 1 2: a dash of one path length, then a gap of two. Because the gap is longer than the path, an offset of 1 hides the whole line, and a stray dot that some browsers paint at the end of a hidden path with round caps stays away.

Note

pathLength works on path, line, circle, rect and the other shape elements, so the same trick draws rings and outlines.

One clock for line and dot

A dot that rides the head of the line must follow exactly the same timing. Two separate animations drift apart, so drive both from one clock. getPointAtLength returns the coordinates at any distance along the path.

getTotalLength() still returns the real length in user units, so the dot lands on the line even though the dashes use the normalized length. The script only touches stroke-dashoffset and one transform, which keeps the work on the cheap side of the browser's rendering pipeline.

Color the route by segment

Stack several copies of the same path, each showing one slice, and reveal them together with a mask. Each segment is a dash of the slice's length, offset by minus its start. A thick white stroke inside the mask uncovers every segment from left to right as the line travels.

Accessibility

Color alone should never carry meaning. If the segments stand for zones or speeds, label them in HTML next to the graphic, and mark the SVG itself aria-hidden when the text says everything it says.

Reduced motion and no JavaScript

People who ask their system for less motion should get the finished route straight away. And visitors or crawlers without JavaScript should never see an empty page. Add a js class to the root element with a one-line script, and apply the hidden starting state only under it.

For the scripted version, check the same preference before starting the clock and jump to the end state.

Keep it cheap and readable

  • Animate the cheap properties. Stick to stroke-dashoffset, transform and opacity. Avoid animating the path data, widths or positions.
  • Name the graphic or hide it. Give the SVG role="img" and an aria-label when it carries meaning, or aria-hidden="true" when it is decoration and the facts sit in nearby text.
  • Put the information in HTML. Search engines and screen readers read text, not strokes. The route is a flourish; the distance, the time and the title belong in the markup.
  • Play it once. A draw that plays once is easier on people and on batteries than one that repeats forever.

In short

Set pathLength, hide the line with a dash that is longer than the path, animate the offset to zero and drive any rider from the same clock. It is a handful of lines, it respects reduced motion, and it leaves your content in the HTML where search engines and screen readers find it. The line drawings on this site use exactly this approach.
